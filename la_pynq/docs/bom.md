## 零、结论先行：不需要任何"必需"的外接电路板

本设计的所有功能都在片内实现，**外部只有线材**：

| 功能 | 实现方式 | 需要外接板吗 |
|---|---|---|
| 信号源 | PL 内自建 `test_gen` | 不需要 |
| 采集 | Pmod A 的 8 根直连 I/O | 不需要 |
| 触发 / 缓冲 | PL 内 RTL + 片内 BRAM | 不需要 |
| 数据存储 | 片内 BRAM（**不用 DDR3**） | 不需要 |
| 波形显示 | 笔记本浏览器（PS 侧 Python） | 不需要 |
| 供电 | micro USB | 不需要 |

**唯一算"板"的两样，都不是必需：**
- **Pmod 转杜邦线转接板**（十几元）—— 纯便利件。不买也行，因为混装杜邦线里的**公对母**那一端能直接插进 Pmod 母座
- **电平转换模块** —— **仅当被测电路是 5V 电平时才需要**

**⚠️ 但有一件东西迟早要有：被测信号源（第一版不需要）。**
第一版用**板内环回**，连外部信号都不用接。最终演示时需要一个真实被测电路，最省的办法是：
- 用你们课程里现成的 **STM32 / Arduino 开发板**（若有，零采购）输出 SPI / UART
- 或用一根杜邦线把 Pmod 的两根针短接（PL 自己输出 → 自己输入）

**"零外接器件"要写进报告，它是你们的技术优势：**
- 采集／触发／缓冲／协议分析全在片内，没有外挂 ADC / DAC / 存储 / 显示器件
- 外部件成本只有几十元的线材
- **可复现性**：任何人拿到一块 PYNQ-Z2 加几根杜邦线就能复现 → 直接对应"文档质量与可复现性"15 分
- 注意表述：这是因为**我们主动把作品定位在数字侧**，所以不需要外挂模拟器件；不要说成"买不起"

## 一、必需（不买就动不了）

| # | 物品 | 规格要求 | 用途 | 量级估价 |
|---|---|---|---|---|
| 1 | **microSD 卡** | **≥16GB**，Class 10 / A1。官方最低 8GB，但 8GB 装 PYNQ v3.1.1 后空间紧张，易更新失败 | PYNQ 系统**只能从 SD 卡启动**（板上只有 16MB QSPI Flash）。**这是全套清单里最关键的一样** | 20–40 元 |
| 2 | **microSD 读卡器** | 必须支持 **microSD**（或买带卡套的 SD 读卡器）。若笔记本自带 SD 槽可省 | 把镜像烧进卡 | 10–20 元 |
| 3 | **网线** | 普通 RJ45 跳线，1–2 米 | PYNQ-Z2 **无 WiFi**，Jupyter 只能走网线 | 5–15 元 |
| 4 | **USB 转网口转换器** | USB-A 或 Type-C 视笔记本而定 | **仅当笔记本没有 RJ45 网口时必需**（轻薄本常见）。⚠️ 下单前先看自己的笔记本 | 30–60 元 |

## 二、项目必需

| # | 物品 | 规格要求 | 用途 | 量级估价 |
|---|---|---|---|---|
| 5 | **杜邦线混装包** | 2.54mm 间距，建议买**公对公 / 公对母 / 母对母各 40 根**的混装包 | 从 Pmod 接线。<br>**注意：Pmod 是母座，插进去的一端必须是公头** | 20–30 元 |
| 6 | **Pmod 转杜邦线转接板** | 2×6 Pmod 转标准排针 | **可选便利件**：转成标准排针后接线更整齐，以后夹探针也方便。**不买也行**——混装杜邦线里的**公对母**那一端能直接插进 Pmod 母座 | 10–20 元 |

## 三、可选（不急，W3 之后再买）

| # | 物品 | 规格要求 | 用途 | 量级估价 |
|---|---|---|---|---|
| 7 | **鳄鱼夹 / 测试钩** | 一头鳄鱼夹或测试钩，一头母头杜邦 | 夹到被测电路的焊点/元件脚上。**第一版用板内环回 + 杜邦线短接，暂时用不到** | 10–20 元 |
| 8 | **USB 逻辑分析仪** | 8 通道 / 24MHz 那一档（最便宜的） | 三个用途：① 让你**立刻**明白这东西是干什么的；② 给你"好用长什么样"的体验参照；③ 报告里现成的对照组 | 20–40 元 |
| 9 | **电平转换模块 / 分压电阻** | 双向电平转换（5V↔3.3V） | **仅当被测电路是 5V 电平时才需要**。手册警告：驱动超过 5V 会损坏 Zynq | 10–20 元 |

## 四、明确不要买

| 物品 | 为什么不要 |
|---|---|
| **MIPI CSI 摄像头** | PYNQ-Z2 根本没有 MIPI 接口 |
| **USB 摄像头** | 走 PS 侧 Linux，图像**根本不进 PL**，"FPGA 加速"成空话 |
| 带 FIFO 的并口摄像头（OV7725+AL422B） | 本项目不做视觉，用不上 |
| 12V 电源适配器 | USB 供电够用。等 PL 跑满觉得不稳再加（那时把跳线 J9 拨到 REG） |
| HDMI 线 | 第一版波形在笔记本浏览器显示，不出 HDMI |

## 五、合计

**最低配置（1–6 项）**：约 **60–120 元**（不含 USB 转网口）
**加可选项**：约 **100–180 元**

## 六、下单前的三个自查

1. **笔记本有没有 RJ45 网口？** 没有就要加 USB 转网口转换器。
2. **跳线状态**：`JP1 = SD`（启动模式）、`J9 = USB`（供电来源）。
3. **microSD 卡槽在板子背面。**

## 七、到货后的执行顺序

1. 烧 PYNQ-Z2 **v3.1.1** 镜像到 microSD（用 balenaEtcher 或 Win32DiskImager）
2. 插卡、插 USB、插网线，开机
3. 笔记本网口设静态 IP `192.168.2.x`（x≠99）、掩码 `255.255.255.0`、网关留空
4. 浏览器开 `http://192.168.2.99`，账号密码都是 `xilinx`
5. 跑官方 base overlay 的 LED 例子 → **环境成立**
6. 用自己生成的 bitstream + .hwh 测 `Overlay()` → **验证 PYNQ 与 Vivado 2025.2 的交接点**

# Pmod 接线与引脚对照

## 两个 Pmod 座

| 座 | 丝印 | 作用 |
|---|---|---|
| **Pmod A** | A / JA | **8 路输入** —— 逻辑分析仪的探头，接到界面的 CH0~CH7 |
| **Pmod B** | B / JB | **测试信号源**，可用杜邦线回接到 Pmod A；也能整体关掉 |

两个都是 2×6 母座，针号按手册编号 1~12，**以座子旁边的丝印为准**：

```
      1     3     5     7     9    11
    ┌─────┬─────┬─────┬─────┬─────┬─────┐
    │ P   │ P   │ GND │ P   │ P   │ GND │
    ├─────┼─────┼─────┼─────┼─────┼─────┤
    │ N   │ N   │ 3V3 │ N   │ N   │ 3V3 │
    └─────┴─────┴─────┴─────┴─────┴─────┘
      2     4     6     8    10    12
```

**针 5 / 6 / 11 / 12 是电源，不要接。**

## 座子怎么看（重要）

板子上印的是**列号 1~6**，不是 1~12。一个 2×6 母座 = **6 列，每列上下两根针**：

```
     ┌───┬───┬───┬───┬───┬───┐
方焊盘│ ● │ ● │ ● │ ● │ ● │ ● │   ← 这一排 = 手册里的 _P
     ├───┼───┼───┼───┼───┼───┤
圆焊盘│ ● │ ● │ ● │ ● │ ● │ ● │   ← 这一排 = 手册里的 _N
     └───┴───┴───┴───┴───┴───┘
印字   6   5   4   3   2   1        ← 列号（方形焊盘那一端是 1）
```

**针 1 的认法**：那一端有一列焊盘是**方的**（其余是圆的），旁边印着 `1`。

## 按丝印列号的对照表

| 印字 | 方焊盘那排（P） | 圆焊盘那排（N） | 接到 A 座 | 界面通道 |
|---|---|---|---|---|
| **1** | **UART TX** | 方波 976.6 Hz | **同列 1** | CH0 / CH1 |
| 2 | 方波 651.0 Hz | 方波 488.3 Hz | 同列 2 | CH2 / CH3 |
| 3 | GND | 3V3 | **不接** | — |
| **4** | **I2C SCL** | **I2C SDA** | **同列 4** | CH4 / CH5 |
| 5 | 方波 162.8 Hz | 方波 122.1 Hz | 同列 5 | CH6 / CH7 |
| 6 | GND | 3V3 | **不接** | — |

> 表里的频率按 **62.5 kSa/s 采样**算。方波是按采样点分频产生的，采样率一改频率就跟着变：
> `f = 采样率 ÷ 周期点数`（列 1 圆焊盘 64 点，列 2 两排 96/128 点，列 5 两排 384/512 点）。
> UART 模式是 1.5625 MSa/s，这时列 1 圆焊盘那根会变成 24.4 kHz。

手册里的 12 针编号（1~12）只在寄存器文档和 XDC 里用，**板子上看不到**，接线一律看丝印列号。

## Pmod B 总开关

界面上「**Pmod B：开/关**」按钮（对应寄存器 `CTRL.bit5`）：

- **开**（默认）：8 根针驱动测试信号
- **关**：8 根针 **高阻**，板子不再驱动它们

关掉之后才能把 Pmod A 接到真实被测电路——否则如果 Pmod A 上接着别人的信号、
而 Pmod B 还在推自己的方波，两边会打架（本板的 Pmod A 输入有上拉，悬空读高）。

## 输出频率为什么是这些数

输出方波**由采样节拍 `smp_en` 分频产生**，周期固定为整数个采样点：

```
通道(针 2/3/4/9/10)  周期(采样点)  64   96  128  384  512
```

所以无论采样率调到多少，**每个周期永远是整数个采样点**，重建出的方波边沿严格对齐，
不会出现"偶尔窄一拍"。

反过来，如果用固定时钟分频（比如 62.5MHz ÷ 2^14 = 3.815 kHz），在 62.5 kHz 采样下
每周期是 **16.38** 个点，小数部分会让边沿逐周期漂移，大约每 5 个周期就有一个边沿
落在两个采样点之间，波形就缺一拍。**那个现象不是硬件故障，是采样相位抖动。**

> 表格里的频率按 **62.5 kHz 采样**算。采样率改成别的值时，输出频率按比例变化
> （因为周期以采样点计），但**永远保持整数倍关系**，波形始终规整。

## 怎么接

**同列对接**：B 的第 k 列 → A 的第 k 列，**方焊盘对对方焊盘、圆焊盘对圆焊盘**
（两个座子完全一样，同列同排一一对应，别把一列里两根对调）。

```
协议演示（3 根）：
    列 1：B 方焊盘 → A 方焊盘      （UART，看 CH0）
    列 4：B 方焊盘 → A 方焊盘      （SCL，看 CH4）
    列 4：B 圆焊盘 → A 圆焊盘      （SDA，看 CH5）

频率阶梯（任选）：
    列 2 两排 → 同列同排      （651 / 488 Hz，看 CH2/CH3）
    列 5 两排 → 同列同排      （163 / 122 Hz，看 CH6/CH7）
```

**列 3、列 6 是 GND 和 3V3，一根都别接。**

如果同一列两根对调（方焊盘接到圆焊盘），UART 会跑到 CH1、SCL 跑到 CH5 —— 功能正常，只是通道错位。

## 验证步骤（视频里照这个演）

**A. UART 解码（列 1：方焊盘对上方焊盘）**

1. 接 **列 1：B 方焊盘 → A 方焊盘**
2. 刷新网页，点 **「▶ 开始采集」**
3. 「解码」选 **UART（CH0）**，采样率自动设到 1.5625 MHz
4. CH0 上出现一串 UART 帧，每帧标出解出的字节，可打印字符带引号：
   `50 'P'` `59 'Y'` `4E 'N'` `51 'Q'` …，最后一位是 **递增的数字**（`PYNQ-LA0` → `PYNQ-LA1` …）
5. **拔线 → 帧标注全部消失，CH0 变成一条直线**

> 最后一位每轮 +1，是故意设计的：固定八字节循环容易被怀疑"是不是预置的"，
> 递增计数一看就是活的。

**B. I2C 解码（列 4：方焊盘=SCL、圆焊盘=SDA）**

1. 接这两根（同一列里方焊盘那根 = SCL、圆焊盘那根 = SDA，别对调）
2. 「解码」选 **I2C（CH4+CH5）**，采样率自动设到 3.125 MHz
3. 左侧 CH4/CH5 的名字变成 `SCL` / `SDA`，波形上标出 `START` / `A0` / `55` / `AA` / `ACK` / `STOP`
4. 一帧（5.24 ms 窗口）里能看到 8~9 个完整事务
5. **拔掉 SCL 那根 → 标注全部消失**

**C. 频率阶梯（列 2 / 列 5）**

1. 「解码」选 **关闭**，接 列 2 方焊盘 → A 座同列方焊盘
2. CH2 出现 **651 Hz** 方波
3. 换到列 2 圆焊盘那根，**CH3 出现 488 Hz**
4. **按板上 BTN0 → 采集停；再按一下 → 恢复**

## 常见问题

| 现象 | 原因 |
|---|---|
| 打开页面是空的 | 默认停止，点「▶ 开始采集」 |
| 8 路全平 | 没接线，或者接在了别的针上 |
| 接了线还是全平 | **Pmod B 被关掉了**，点「Pmod B：开」 |
| CH0 有波形但没字节标注 | 采样率不是 1.5625 MHz（每位必须 16 个点），或「解码」选了关闭 |
| I2C 没标注 | 采样率不是 3.125 MHz；或同一列两根对调（方焊盘=SCL、圆焊盘=SDA） |
| 某路全高不变 | 线没插到底，或插到了 GND/3V3 |
| 通道有波形但编号对不上 | 接错列了，或者同一列两根对调 |
| 按 BTN0 后采集中断了 | 正常，再按一次恢复 |

## 这套演示能证明什么

- ✅ **输入引脚 → 同步器 → 采样 → 缓冲 → AXI → 浏览器** 整条链路是真的在工作
- ✅ 拔线即失效，回放动画做不到
- ✅ 5 路频率各不相同且与表格一致，证明通道映射正确
- ⚠️ 但信号是板子自己发的，不是第三方被测设备。**如果评委问"被测设备也是你自己的"，如实回答**：
  没有第三方信号源，所以用 Pmod B 回环；这套演示证明的是**采集通路的真实性**。
- ✅ 有真实 I2C 传感器 / UART 模块时：**关掉 Pmod B**，把它的 SCL 接列 4 方焊盘那根、SDA 接圆焊盘那根，
  或 TX 接到列 1 方焊盘那根，直接就能解 —— 解码器在 PL 里，唯一要求是采样率够（UART ≥ 4 倍波特率，
  I2C ≥ 8 倍 SCL 频率）。
